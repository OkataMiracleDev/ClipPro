# Milestone M1: Engine

Date: 2026-10-27 · Branch `dev`

**Result:** `clippro-cli` imports footage into a `.clippro` project, analyses it in parallel with checkpoints, and scores it with any of the 19 presets. It prints selects as text or JSON.

```
clippro-cli analyze testdata/gen --project corpus.clippro      # 40 clips
clippro-cli score corpus.clippro --preset "Talking Head" --sort score
clippro-cli score corpus.clippro --preset Pan --json
```

## Performance (dev laptop, i7-1185G7 / Iris Xe)
Machine state matters a lot: the same build measured about 4× slower at a throttled 1.2 GHz clock under background load. Numbers below are at full clock unless stated.

| Measure | Result | SPEC §22 target |
|---|---|---|
| Re-score 100 h after a weights change | 108 ms | ≤ 150 ms ✔ |
| Single clip, 1 worker, 480p | 9× realtime | — |
| Single clip, 1 worker, 720p | 7.3× realtime | — |
| 2-min 720p clip, 4 workers (sections) | ≈15× realtime | — |
| 4K H.264 at 4 Hz, all groups | not yet re-measured after optimisation (was 1.5× before) | GPU-ref ≥ 20×, CPU-ref ≥ 5× |

**Known gap:** 4K throughput. The remaining costs per sample are spatial (~6 ms), motion (~5 ms ×2) and the working-image downscale. Planned next steps: SIMD/fused spatial pass and P8 GPU kernels.
